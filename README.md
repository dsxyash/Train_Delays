A data science project was conducted based on a regression analysis where the main topic Train Delays. The background for this project is based on today's world where trains are being more delayed because of factors such as route congestion, weather condition and where the route congestion could vary during different time periods. Regression algorithms were explored and utilized with libraries such as Pandas, Seaborn, whereas some base models and ensemble models were built using Scikit-Learn, and hyperparameters were added where an evaluation over the model performance played a big role in choosing the best model to predict the train delays.
